Product details

Store listing tab. Title and summary come from the package (manifest), so there's nothing to enter for them.

DescriptionRequired
Stop pasting bare ClickUp URLs. ClickUp Link Copier copies tasks as clickable titles, so Slack, Notion, Google Docs and Gmail show what each task is:

• [APP-412] Add progress bar to signup steps
• [APP-405] Return 404 for archived projects

instead of a list of https://app.clickup.com/t/… links nobody can tell apart.

COPY ONE TASK
Hover any task in List view, a card in Board view, or a subtask on an open task, and click the link button. On an open task, use Copy link in the header. One task pastes as a single clickable title.

COLLECT A LIST
Hold Alt (⌥ Option on Mac) and click tasks anywhere in ClickUp: rows, cards, subtasks, or task links in docs and comments. Collected tasks are highlighted, and a dock at the bottom shows exactly what will paste. Drag to reorder, then click Copy or press Alt+Shift+C (⌥⇧C). Several tasks paste as a bulleted list.

PASTES RIGHT EVERYWHERE
Each copy carries a rich version and a plain one. Slack, Notion, Google Docs and Gmail get clickable titles. Code editors, GitHub and terminals get Markdown links. Prefer "Title — url" or bare URLs? It's a setting.

TASK IDS YOUR WAY
Titles start with the task ID, like [APP-412], and use your custom task IDs where your space has them. Turn IDs off with one switch.

FEELS LIKE CLICKUP
The buttons are styled like ClickUp's own and follow its light and dark themes. Removing, clearing and copy-and-clear can all be undone.

PRIVATE BY DESIGN
No server, no analytics, no account. The extension runs only on app.clickup.com and keeps your list in your browser's local storage. The code is open source under the MIT license:
https://github.com/semenov-k/clickup-link-copier

ClickUp Link Copier is an independent project and is not affiliated with or endorsed by ClickUp.

Privacy practices

Privacy practices tab. Required before you can submit.

Single purpose description

Copy ClickUp tasks as clickable title links, either one task at a time or as a collected list, so they paste as readable links into chat, docs and email.

Justification: storage

Saves the list of tasks the user collects and the user's paste settings (task ID prefix, plain-text format, clear after copying) in the browser's local storage, so the list is shared between ClickUp tabs and the toolbar popup and survives page reloads. Nothing is sent anywhere.

Justification: clipboardWrite

Writes the selected task titles and links to the clipboard, as rich text and plain text, when the user clicks a Copy button or presses the copy shortcut. This is the extension's core feature.

Justification: declarativeContent

Enables the toolbar button only on app.clickup.com pages and greys it out everywhere else. Chrome evaluates the page rule itself, so the extension never reads the addresses of other sites.

Justification: host permission (https://app.clickup.com/*)

Adds Copy link and Add to list buttons to ClickUp pages and reads the title and link of the task the user clicks, so it can copy them. The extension runs on no other site.
